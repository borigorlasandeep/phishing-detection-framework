# Phishing Detection Framework

An AI-powered cybersecurity project that detects:

- Phishing URLs
- Smishing SMS messages
- Malicious links

## Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- HTML/CSS
- SQLite

## Features

- URL Analysis
- SMS Analysis
- User Authentication
- Scan History
- Dashboard Analytics

## Installation

```bash
pip install -r requirements.txt
python main.py
